(Dolmen)">دولمين</span>" [النَّصَبُ الحَجَري]. هل تَرى؟ شَخْصٌ جَاثِمٌ عِندَ قاعِدَتِه. مُقَيَّدٌ بَسلاسِلَ إلى "<span class="tt tt-lore" data-tt="أعمدة حجرية عملاقة تشكل جزءاً من بنية السحر البدائي. (Menhir)">مينهير</span>" [العَمُود الصَّخْرِي]. كُلُّ شَيءٍ مَحجُوبٌ بِالدُّخان، دُخانٌ يُخَدِّرُ عَقلي. لَقَد استُولِيَ على "<span class="tt tt-lore" data-tt="نصب حجري يمثل عقداً سحرية بدائية. (Dolmen)">دولمين</span>".»</p>
            <p>حَدَّقَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> في البَلاطَة. كانَ الشَّكْلُ شَبَحِيَّاً، وبَدَت رُؤيَتُهُ تَغْتَشُّ كُلَّما أطالَ النَّظَر. «مَن فَعَلَ هَذا؟»</p>
            <p>«غَرِيب. دَخِيل.»</p>
            <p>«إلَه؟»</p>
            <p>دَلَّكَ <span class="tt tt-name" data-tt="Kuru Qan">كورو كان</span> جَبينَهُ المُغَضَّنَ بِأصابِعِهِ وهو يُواصِلُ السَّير. «نَعَم. لا. <span class="tt tt-phil" data-tt="يعكس هذا المقطع نظرة عالم مالازان الفلسفية للآلهة؛ فهم ليسوا خالقين مطلقين، بل كيانات تتشكل وتستمد قوتها من إيمان البشر ورغباتهم ومخاوفهم، مما يجعلهم عرضة للضعف.">نَحنُ لا نُقِيمُ وَزناً لِفِكرَةِ الآلِهَة. إنَّهُم مُجَرَّدُ طارِئِينَ لا يُساوي شَيئاً مُقارَنَةً بِالـ مَقامات. مُعظَمُهُم لَيسوا حَقِيقيِّينَ أصلاً، بَل هُم مُجَرَّدُ تَجَلِّياتٍ لِرَغباتِ الشُّعوبِ وآمالِها. ومَخاوِفِها.</span> وبِالطَّبْع،» أضافَ، «أحياناً هذا كُلُّ ما يَلزَم.»</p>
            <p>«ماذا تَقصد؟»</p>
            <p>هَزَّ <span class="tt tt-name" data-tt="Kuru Qan">كورو كان</span> رَأسَه. «و<span class="tt tt-lore" data-tt="قوة كونية غامضة تتجلى على شكل بيوت حية تقوم بابتلاع وحبس الكيانات والآلهة التي تهدد نسيج الوجود. (Azath Hold)">هولد الأزات</span>، هذا يُقْلِقُني بِشِدَّة. البَلاطَةُ المَركَزِيَّة، <span class="tt tt-lore" data-tt="المركز النابض أو نواة بيت الأزات، والذي من خلاله يتحكم البيت في طاقاته وسجنائه. (Heartstone)">هارتستون</span> [حَجَرُ القَلب]، هل تَشعُرُ بِها؟ لَقَد مَاتَ "<span class="tt tt-lore" data-tt="نواة بيت الأزات. (Heartstone)">هارتستون</span>" <span class="tt tt-lore" data-tt="البيوت الكونية التي تحفظ التوازن السحري. (Azath)">الأزات</span> يا صَدِيقي. تَجَمَّعَتِ البَلاطاتُ الأخرى حَولَهُ في النِّهايَة، مُنْكَمِشَةً على بَعضِها مِثْلَما يَتَجَمَّعُ الدَّمُ في جَسَدٍ جَرِيح. لَقَد اختُرِقَ المَدْفَن، وباتَت <span class="tt tt-lore" data-tt="عنصر سحري يمثل العبور بين العوالم أو المقامات.">البَوابةُ</span> بِلا حِراسَة. يَجِبُ أن تَقومَ بِرِحلَةٍ لِأَجْلي إلى البُرجِ المُرَبَّع يا <span class="tt tt-lore" data-tt="رتبة عسكرية رفيعة. (Finadd)">فيناد</span>. واذهَبْ مُتَسَلِّحاً.»</p>
            <p>«عَمَّن يَجِبُ أن أبحَث؟»</p>
            <p>«أيُّ شَيءٍ غَيرِ طَبِيعي. أرضٌ مُتَصَدِّعَة. ولَكِن كُن حَذِراً؛ فالسُّكَّانُ القابِعونَ في تِلكَ المَدافِنِ لَيسوا مَوْتى.»</p>
            <p>«حَسَناً.» تَفَحَّصَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> أقْرَبَ <span class="tt tt-lore" data-tt="ألواح سحرية تُستخدم في ليذر للتنبؤ بالمستقبل وقراءة المقامات.">البَلاطات</span>. «هل هُناكَ المَزيد؟»</p>
            <p>تَوَقَّفَ <span class="tt tt-name" data-tt="Kuru Qan">كورو كان</span>، وارتَفَعَ حاجِباه. «المَزيد؟ لَقَد استَيْقَظَ <span class="tt tt-lore" data-tt="أحد المقامات القديمة المرتبطة بالتنانين والفوضى البدائية.">مَقامُ التِّنِّين</span>. <span class="tt tt-lore" data-tt="كائنات مجنحة مرعبة تنحدر من سلالة التنانين (الآلينت)، وتعتبر نسخاً أصغر وأكثر وحشية. (Wyval)">وايفال</span> [أشْباهُ التَّنانِين]. <span class="tt tt-lore" data-tt="كيان أو قوة مرتبطة بالمقامات، ترمز إلى العنف والقرابين.">شارِبُ الدِّماء</span>. <span class="tt tt-lore" data-tt="عنصر سحري يمثل العبور بين العوالم.">البَوابة</span>. <span class="tt tt-lore" data-tt="دور ضمن نظام المقامات، يمثل الشريك أو الداعم للقوة الحاكمة.">القَرِين</span>. ومِن بَينِ "محاور الارتِكاز"، اتَّخَذَ "<span class="tt tt-lore" data-tt="إله قديم يرتبط بمقام 'العرش الخالي'. يمثل الصدفة وتغير المصائر، ويتلاعب بالأحداث. (Errant)">إيرانت</span>" [التَّائِه] مَوقِعَهُ الآن في مَركَزِ الأمور. "<span class="tt tt-lore" data-tt="مجموعة الكيانات التابعة لمقام ما.">القَطِيع</span>" يَقتَرِب، و"كاشِفُ الهَيْئة" أصْبَحَ "<span class="tt tt-lore" data-tt="وحش سحري هجين مرعب يتشكل من دمج عدة كائنات معاً. (Chimera)">كيميرا</span>" [وَحشاً مُهَجَّناً]. أمَّا "<span class="tt tt-lore" data-tt="كيان مرتبط بمقام الجليد البدائي، وهي تشير هنا إلى الجاغوت التي تصطاد الشياطين.">صَيّادَةُ</span>" مَقامِ الجَلِيد، فَهِيَ تَسْلُكُ مَسالِكَ مُتَجَمِّدَة. "<span class="tt tt-lore" data-tt="بطاقة أو رمز يمثل البراءة المهددة أو التجديد في قراءة المقامات.">الطِّفْل</span>" و"<span class="tt tt-lore" data-tt="رمز يمثل البدايات الجديدة أو الخطر الكامن.">البَذْرَة</span>" يَدُبُّ فِيهِما النَّشاط. و<span class="tt tt-lore" data-tt="مقام سحري غامض وغير مستقر، مرتبط بالإله 'الإيرانت' والصدفة العمياء.">المَقامُ الخالِي</span> — كَما تَرى بِوُضوح — أصْبَحَ مَحجُوباً. كُلُّ بَلاطَة. هُناكَ ظِلٌّ يَقِفُ خَلْفَ "العَرشِ الخالِي". وانظُر، "المُخَلِّص" و"الخائِن"، لَقَدِ التَحَما. لَقَد أصْبَحا كِياناً واحِداً. كَيفَ يُمكِنُ لِهذا أن يَحدُث؟ "المُتَجَوِّل"، "السَّيِّدة"، "المُراقِب" و"الماشِي"، كُلُّهُم مُخْتَفون، مَحجُوبونَ بِحَرَكَةٍ غامِضَة. أنا خائِفٌ يا <span class="tt tt-lore" data-tt="رتبة عسكرية رفيعة. (Finadd)">فيناد</span>.»</p>
            <p>«<span class="tt tt-lore" data-tt="أعلى رتبة سحرية في إمبراطورية ليذر. (Ceda)">سيدا</span>، هل سَمِعتَ أنباءً عَنِ الوَفْد؟»</p>
            <p>«الوَفْد؟ لا. مُنذُ لَحْظَةِ وُصولِهِم إلى قَريةِ <span class="tt tt-lore" data-tt="الحاكم القوي الذي وحد قبائل التيست إيدور المتناحرة، واسمه الحقيقي هانان موساغ. (Warlock King)">وارلوك كينغ</span> [المَلِك السَّاحِر]، انقَطَعَ كُلُّ اتِّصالٍ بِهِم. لَقَد حُجِبَ بـ<span class="tt tt-lore" data-tt="سحر مستمد من خندق الظل (كورالد جالين)، يتميز بقوته التدميرية.">سِحرِ</span> <span class="tt tt-lore" data-tt="التيست إيدور، وهم عرق ذو بشرة رمادية يُعرفون بأبناء الظل. (Edur)">الإيدور</span>، وهو نَوْعٌ لَم نَعْهَدْهُ مِن قَبْل. هُناكَ الكثيرُ مِمَّا يُقْلِق. الكثير.»</p>
            <p>«يَجِبُ أن أُغادِرَ الآن يا <span class="tt tt-lore" data-tt="أعلى رتبة سحرية. (Ceda)">سيدا</span>، ما دامَ هُناكَ ضَوءٌ بَعْد.»</p>
            <p>«مُوافِق. ثُمَّ عُد إلى هُنا بِما اكتَشَفْتَه.»</p>
            <p>«حَسَناً.»</p>

            <div class="divider">◆ ◆ ◆</div>

            <p>صَعِدَ المَسارُ المُؤَدِّي إلى المَحاجِرِ بِشَكْلٍ مُتَعَرِّجٍ نَحوَ فَجْوَةٍ في سَفْحِ التَّل. كانت أشجارُ الغابَةِ الكَثِيفَةِ على الجَوانِبِ مُغَطَّاةً بِغُبارٍ أبْيَض. وبَدَتِ الماعِزُ وهي تَسْعُلُ في الظِّلّ.</p>
            <p>تَوَقَّفَ <span class="tt tt-name" data-tt="Bugg">باق</span> لِيَمْسَحَ الحَصَى المُتَعَرِّقَ عَن جَبِينِه، ثُمَّ واصَلَ السَّير.</p>
            <p>مَرَّت بِهِ قَبْلَ وَقتٍ قَصِيرٍ عَرَبَتانِ مَلِيئَتانِ بِقاطِعِي الأحجار، وجاءَتْ مِن رَئيسِ العُمَّالِ المُحْبَطِ أنباءٌ غَيرُ سارَّةٍ تُفيدُ بِأنَّ الطَّاقَمَ رَفَضَ العَمَلَ في المَحْجَرِ بَعْدَ الآن، على الأقَلِّ حتَّى تُحَلَّ المُشْكِلَة.</p>
            <p>لَقَد فُتِحَتْ فَجْوَةٌ عَن غَيرِ قَصْد، كانَ يَسكُنُها مَخلوقٌ مِن نَوْعٍ ما، لَقَد كانَ سَجِيناً هُناكَ لِما يَجِبُ أن يَكونَ زَمَناً طَويلاً جِدَّاً. لَقَد سُحِبَ ثَلاثَةٌ مِنَ العُمَّالِ إلى الداخِل، ولَم تَدُمْ صَرخاتُهُم طَويلاً. ولَم يَكُن حالُ "<span class="tt tt-lore" data-tt="ساحر متخصص في سحر الموت والتلاعب بالأرواح والجثث. (Necromancer)">النيكرومانسر</span>" [مُستَحْضِر الأرواح] المُسْتَأجَرِ بِأفضَلَ مِنهُم.</p>
            <p>وَصَلَ <span class="tt tt-name" data-tt="Bugg">باق</span> إلى الفَجْوَةِ ووَقَفَ يَنظُرُ إلى أسفَلَ حُفْرَةِ المَحْجَرِ بِجَوانِبِها الحَجَرِيَّةِ الجِيرِيَّةِ الهَنْدَسِيَّةِ المَحفُورَةِ بَعِيداً في الأرضِ المُحِيطَة. كانَت فَوهَةُ التَّجْويفِ بالكادِ مَرئِيَّةً بِالقُربِ مِن مِنطَقَةٍ شَهِدَت أعمالاً حَدِيثَة.</p>
            <p>شَقَّ طَرِيقَهُ إلى الأسفَل، واقْتَرَبَ لِمَسافَةِ عِشْرِينَ خُطْوَةً مِنَ الكَهْفِ قَبْلَ أن يَتَوَقَّف.</p>
            <p>فَجْأةً، أصْبَحَ الهَواءُ قارِساً كالعَلْقَم. وبِتَقْطِيبَةٍ على وَجْهِه، خَطا <span class="tt tt-name" data-tt="Bugg">باق</span> إلى جانِبٍ واحِدٍ وجَلَسَ على كُتْلَةٍ مِنَ الحَجَرِ الجِيرِيّ. راقَبَ الصَّقِيعَ وهو يَتَشَكَّلُ على الأرضِ إلى يَسارِ الكَهْف، مُمْتَدَّاً في نُقْطَةٍ نَحوَ الفَتْحَةِ المُظلِمَة، بَيْنما انْتَشَرَ الطَّرَفُ المُقابِلُ بِشَكْلٍ أوسَعَ في دَوَّامَةٍ مِنَ الضَّباب. دَوى صَوتُ تَحَطُّمِ الجَلِيدِ تَحتَ الأقدام، ثُمَّ ظَهَرَ شَخْصٌ مِنَ الطَّرَفِ المُتَّسِع، وكأنَّهُ خَرَجَ مِنَ العَدَم. قامَةٌ فارِعَة، عارِيَةٌ مِنَ الحَوضِ فما فَوق، بِبَشَرَةٍ رَمادِيَّةٍ مائِلَةٍ لِلخُضْرَة. شَعْرٌ أشْقَرُ طَوِيلٌ ذو خُصُلاتٍ داكِنَةٍ يَنْسَدِلُ بِحُرِّيَّةٍ على كَتِفَيها وظَهْرِها. عَيْنانِ رَمادِيَّتانِ فاتِحَتان، وحَدَقَتاهُما شَقَّانِ رَأْسِيَّان. أنيابٌ مُغَطَّاةٌ بِالفِضَّة. كانت أُنثى، ذاتَ صَدْرٍ مُمْتَلِئ. تَرْتَدي تَنُّورَةً قَصِيرَة، وهي قِطعَةُ مَلابِسِها الوَحِيدَةُ باستِثْناءِ خُفِّ "الموكاسين" المَرْبوطِ بَسُيُورٍ جِلدِيَّة، وحِزامٍ عَريضٍ يَحمِلُ نِصْفَ دَرْزَنَةٍ مِنَ الأغمادِ التي تَسكُنُها خَناجِرُ لِلطَّعْن.</p>
            <p>كانَ تَرْكِيزُها مُنْصَبَّاً على الكَهْف. وَضَعَت يَدَيها على خَصْرِها وتَنَهَّدَت بِصَوتٍ مَسْموع.</p>
            <p>«لَن يَخرُج،» قالَ <span class="tt tt-name" data-tt="Bugg">باق</span>.</p>
            <p>نَظَرَت نَحوَه. «بِالطَّبْع لَن يَفْعَل، ما دُمتُ أنا هُنا.»</p>
            <p>«أيُّ نَوْعٍ مِنَ الشَّياطِينِ هو؟»</p>
            <p>«جائِعٌ ومَجنون، ولَكِنَّهُ جَبان.»</p>
            <p>«هل أنتِ مَن وَضَعَهُ هُناك؟»</p>
            <p>أومَأَت بِرَأسِها. «تَبَّاً لِلبَشَر. لا يُمكِنُهُم تَرْكُ الأشياءِ وشَأنَها.»</p>
            <p>«أشُكُّ في أنَّهُم كانوا يَعْلَمون يا <span class="tt tt-lore" data-tt="عرق قديم وقوي جداً يتميز بصلاته العميقة بسحر الجليد. يفضلون العزلة وغالباً ما يُعتبرون تهديداً أسطورياً. (Jaghut)">جاغوت</span>.»</p>
            <p>«لَيسَ عُذْراً. إنَّهُم يَحفُرونَ دائِماً. يَحفُرونَ هُنا، ويَحفُرونَ هُناك. لا يَتَوَقَّفونَ أبداً.»</p>
            <p>أومَأَ <span class="tt tt-name" data-tt="Bugg">باق</span> بِرَأسِه، ثُمَّ سأل: «إذاً، ماذا الآن؟»</p>
            <p>تَنَهَّدَت مَرَّةً أخرى.</p>
            <p>تَحَوَّلَ الصَّقِيعُ عِندَ قَدَمَيها إلى جَلِيدٍ زاوِيّ، زَحَفَ بَعْدَ ذلِكَ إلى فَوْهَةِ الكَهْف. نَمَا الجَلِيدُ بِسُرعَة، مَالِئاً الحُفْرَة. أنَّ الحَجَرُ المُحِيطُ وصَرَّ، ثُمَّ تَصَدَّعَ، لِيَكشِفَ عَن جَلِيدٍ صَلْبٍ تَحْتَه. انْهالَتِ الأرضُ الرَّملِيَّةُ وقِطَعُ الحَجَرِ الجِيرِيّ.</p>
            <p>ضاقَت نَظرَةُ <span class="tt tt-name" data-tt="Bugg">باق</span> نَحوَ الشَّكْلِ الغَرِيبِ المَحْبوسِ في مَركَزِ الجَلِيدِ المُتَصاعِدِ مِنهُ البُخار. «<span class="tt tt-lore" data-tt="نوع من الشياطين المرعبة والمجنونة في عالم مالازان، تُعرف بجوعها الذي لا ينتهي وطبيعتها الجبانة. (Khalibaral)">خاليبارال</span>؟ لِيُعِنَّا الـ<span class="tt tt-lore" data-tt="الإله المتلاعب بالصدف والمصائر. (Errant)">إيرانت</span>، أنا سَعيدٌ لأنَّكِ قَرَّرْتِ العَودةَ يا <span class="tt tt-name" data-tt="Huntress">هانتريس</span> [الصَّيادة].»</p>
            <p>«الآن أحتاجُ إلى العُثُورِ لَهُ على مَكانٍ آخَر. أيُّ اقتِراحات؟»</p>
            <p>فَكَّرَ <span class="tt tt-name" data-tt="Bugg">باق</span> لِفَترَة، ثُمَّ ابْتَسَم.</p>

            <div class="divider">◆ ◆ ◆</div>

            <p>تَقَدَّمَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> بَينَ بَرجيْنِ مُستَدِيرَينِ مُهَدَّمَين، وهو يَخطو بِحَذَرٍ حَولَ كُتَلٍ حَجَرِيَّةٍ مُتَساقِطَةٍ نِصفُ مَخفِيَّةٍ في الأعشابِ الصَّفراءِ القاسِيَة. كانَ الهَواءُ حارَّاً وساكِناً، وضَوءُ الشَّمْسِ كَذَهَبٍ مُنْصَهِرٍ على جُدرانِ البُرج. طارَ الجَرادُ مِن طَرِيقِهِ بِذُعْرٍ طَقْطَقِيّ، وعِندَ الإحساسِ الضَّعِيفِ بِتَحَطُّمِ شَيءٍ تَحتَ قَدَمَيه، نَظَرَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> إلى أسفَلَ لِيَرى أنَّ الأرضَ تَعِجُّ بِالحَياة. حَشَراتٌ، الكثيرُ مِنها لا تَعْرِفُها عَيْناه، ضَخْمَةُ الحَجْم، خَرْقاء، بِألوانٍ باهِتَة، تَتَدافعُ إلى كِلا الجانِبَيْنِ بَيْنَما يَمْشِي.</p>
            <p>وبِما أنَّها كانت تَهْرُبُ جَمِيعُها، لَم يَكُن قَلِقاً بِشَكْلٍ زائِد.</p>
            <p>ظَهَرَ البُرجُ المُرَبَّعُ أمامَ نَظَرِه. إنَّهُ <span class="tt tt-lore" data-tt="قوة كونية غامضة تتجلى على شكل بيوت حية (منازل الأزات) تقوم بابتلاع الكيانات التي تهدد نسيج الوجود. (Azath)">الأزات</span>. وبِعِيداً عَن طِرازِ مِعمارِهِ البِدائِيّ، بَدا أنَّ هُناكَ القليلَ مِمَّا يُمَيِّزُه. شَعَرَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> بِالحَيرَةِ مِن تأكِيدِ <span class="tt tt-lore" data-tt="أعلى رتبة سحرية. (Ceda)">سيدا</span> بِأنَّ هَيْكَلاً مِنَ الحَجَرِ والخَشَبِ يُمكِنُ أن يَكونَ واعِيَاً، أو يُمكِنُ أن يَتَنَفَّسَ بِحَياةٍ خاصَّةٍ بِه. فالبِناءُ يَفْتَرِضُ وُجودَ بَنَّاء، ومَع ذلِكَ زَعَمَ <span class="tt tt-name" data-tt="Kuru Qan">كورو كان</span> أنَّ <span class="tt tt-lore" data-tt="بيوت الأزات الحية. (Azath)">الأزات</span> يَنشأُ بَبَساطَة، ويَتَجَمَّعُ مِن تِلْقاءِ نَفْسِه. مِمَّا يُثيرُ الشُّكوكَ في كُلِّ قانونٍ لِلسَّبَبِيَّةِ وضَعَهُ أجيالٌ مِنَ العُلَماءِ كَحَقِيقَةٍ لا تَقْبَلُ الجَدَل.</p>
            <p>كانتِ الأراضي المُحِيطَةُ أقلَّ غُموضاً، وإن كانت أكثَرَ خُطورَةً بِكَثير. لَم يَكُن هُناكَ شَكٌّ في "<span class="tt tt-lore" data-tt="تلال قبور تحيط ببيوت الأزات، حيث يتم دفن وحبس الكيانات القوية لتظل في سبات أبدي. (Barrows)">الباروز</span>" [تِلالِ المَدافِن] المُحْدَوْدَبَةِ في السَّاحَةِ المَكْسُوَّةِ بِالأعشاب. أشجارٌ مَيِّتَة، مُتَقَرِّحَةٌ ومُتَقَزِّمَة، نَبَتَت هُنا وهُناك، أحياناً مِن أعْلى نُقْطَةٍ في التَّل، ولَكِن في أغْلَبِ الأحيانِ مِن جَوانِبِه. بَدأَ مَسارٌ مُتَعَرِّجٌ مِن بَلاطِ الرُّخامِ أمامَ البابِ الأمامِيّ، وتَمَيَّزَتِ البَوابةُ بِأعْمِدَةٍ خَشِنَةٍ مِن حَجَرٍ غَيرِ مَطْلِيٍّ بِالمِلاط، مُلْتَفَّةٍ حَولَها كُرومٌ وأغصان. أحاطَت بَقايا جِدارٍ مُنْخَفِضٍ بِالأرْض.</p>
            <p>وَصَلَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> إلى حافَّةِ السَّاحَةِ على طُولِ أحَدِ الجَوانِب، البَوابةُ عَن يَمِينِه، والبُرجُ عَن يَسارِه. ورأى على الفَوْرِ أنَّ الكَثيرَ مِنَ المَدافِنِ التي تَقَعُ في مَرمى بَصَرِهِ قَدِ انْهارَتْ في جانِبٍ واحِدٍ على الأقَلّ، وكأنَّ أحشاءَها قَد فُرِغَت مِنَ الدَّاخِل. كانتِ الأعشابُ الضارَّةُ التي تُغَطِّي التِّلالَ مَيِّتَة، ومُسْوَدَّةً كأنَّما أصابةها العَفَن.</p>
            <p>دَرَسَ المَشْهَدَ لِلَحْظَةٍ أطْوَل، ثُمَّ شَقَّ طَرِيقَهُ حَولَ المُحِيطِ نَحوَ المَدْخَل. سارَ بَيْنَ الأعْمِدَة، إلى أوَّلِ بَلاطَةٍ رُخامِيَّة — والتي مالَتْ إلى أسفَلَ نَحوَ جانِبٍ واحِدٍ بِصَوتِ احتِكاكٍ مَعْدَنِيّ. تَرَنَّحَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>، مادَّاً ذِراعَيْهِ لِتَوازُنِ نَفْسِه، وتَمَكَّنَ مِنَ التَّعافِي دونَ سُقوط.</p>
            <p>تَعالَت ضَحكَةٌ حادَّةٌ مِن قُربِ مَدْخَلِ البُرج.</p>
            <p>رَفَعَ نَظَرَه.</p>
            <p>خَرَجَتِ الفَتاةُ مِنَ الظِّلِّ الذي يُلْقِيهِ البُرج. «أنا أعْرِفُك. لَقَد تَبِعْتُ الَّذينَ كانوا يَتْبَعونَك. وقَتَلْتُهُم.»</p>
            <p>«ماذا حَدَثَ هُنا؟»</p>
            <p>«أشياءٌ سَيِّئَة.» اقْتَرَبَت أكثَر، كانت رَثَّةَ الهَيْئَةِ وثِيابُها مُلَطَّخَةٌ بِالعَفَن. «هل أنتَ صَدِيقي؟ كانَ مِنَ المُفْتَرَضِ أن أُساعِدَهُ لِيَبْقى على قَيْدِ الحَياة. ولَكِنَّهُ ماتَ على أيِّ حال، والأشياءُ مَشغولَةٌ بِقَتْلِ بَعْضِها البَعْض. باستِثناءِ الشَّخْصِ الَّذي اختارَهُ البُرج. إنَّهُ يُريدُ التَّحَدُّثَ إلَيْك.»</p>
            <p>«إلَيَّ أنا؟»</p>
            <p>«إلى أحَدِ أصدِقائِي الكِبار.»</p>
            <p>سألَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>: «ومَن هُم أصْدِقاؤكِ الكِبارُ الآخَرون؟»</p>
            <p>«الأُمُّ <span class="tt tt-name" data-tt="Shurq Elalle">شيرك</span>، الأبُ <span class="tt tt-name" data-tt="Tehol Beddict">تيهول</span>، العَمُّ <span class="tt tt-name" data-tt="Ublala Pung">أوبلالا</span>، العَمُّ <span class="tt tt-name" data-tt="Bugg">باق</span>.»</p>
            <p>صَمَتَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>. ثُمَّ قال: «ما اسمُكِ؟»</p>
            <p>«<span class="tt tt-name" data-tt="Kettle">كيتل</span>.»</p>
            <p>«<span class="tt tt-name" data-tt="Kettle">كيتل</span>، كَم شَخْصاً قَتَلْتِ في العامِ الماضي؟»</p>
            <p>أمالَت رَأسَها. «لا أستَطِيعُ العَدَّ بَعْدَ الثَّمانِيَةِ والاثْنَيْن.»</p>
            <p>«آه.»</p>
            <p>«الكثيرُ مِنَ الثَّمانِيَةِ والاثْنَيْن.»</p>
            <p>«وأيْنَ تَذهَبُ الجُثَث؟»</p>
            <p>«أُحْضِرُها إلى هُنا وأدْفَعُها في الأرض.»</p>
            <p>«كُلُّها؟»</p>
            <p>أومَأَت بِرَأسِها.</p>
            <p>«أينَ هو صَدِيقُكِ هذا؟ الَّذي يُريدُ التَّحَدُّثَ إلَيَّ؟»</p>
            <p>«لا أعْرِفُ ما إذا كانَ صَدِيقاً. اتْبَعْنِي. خُطُّ حَيْثُ أخْطو.»</p>
            <p>أمْسَكَت بِيَدِه، وصارَعَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> لِكَبْتِ قَشْعَرِيرَةٍ مِن تِلكَ القَبْضَةِ البارِدَةِ الرَّطْبَة. خَرَجا عَنِ المَسارِ المُرَصَّف، بَينَ تِلالِ المَدافِن، والأرضُ تَتَحَرَّكُ بِشَكْلٍ غَيرِ مُسْتَقِرٍّ تَحتَ كُلِّ خُطْوَةٍ حَذِرَة. كانَ هُناكَ مَزيدٌ مِنَ الحَشَرات، ولَكِن مِن أنواعٍ أقلّ، وكأنَّ نَوْعاً مِنَ الاستِنْزافِ قَد حَدَثَ في أراضي <span class="tt tt-lore" data-tt="بيت الأزات الحي. (Azath)">الأزات</span>. قالَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>: «لَم أسْبِق لي أن رَأيتُ حَشَراتٍ كَهَذِه مِن قَبْل. إنَّها... ضَخْمَة.»</p>
            <p>قالَت <span class="tt tt-name" data-tt="Kettle">كيتل</span>: «قَدِيمَة، مِنَ العُصورِ الَّتي وُلِدَ فِيها البُرج. بَيْضٌ في الأرضِ المُتَصَدِّعَة. تِلكَ البُنِّيَّةُ الَّتي تُشْبِهُ العَصا ولَها رُؤوسٌ في كِلا الطَّرَفَيْنِ هي الأكثرُ شَرارَة. إنَّها تأكُلُ أصابِعَ قَدَمِي عندما أجْلِسُ ساكِنَةً لِفَترَةٍ طَوِيلَة. ومِنَ الصَّعْبِ سَحْقُها.»</p>
            <p>«وماذا عَن تِلكَ الصَّفراءِ الشَّائِكَة؟»</p>
            <p>«إنَّها لا تُزعِجُني. لا تأكُلُ إلا الطُّيورَ والفِئران. هُنا.»</p>
            <p>تَوَقَّفَت أمامَ تَلٍّ مُنْهارٍ جَلَسَت فَوْقَهُ واحِدَةٌ مِن أكبَرِ الأشجارِ في السَّاحَة، كانَ خَشَبُها مُخَطَّطاً بِشَكْلٍ غَرِيبٍ بِاللَّوْنَيْنِ الرَّمادِيِّ والأسوَد، والأغصانُ والفُروعُ تَبرُزُ في مُنحَنَياتٍ بَدَلاً مِن زَوايا حادَّة. انْتَشَرَتِ الجُذورُ عَبْرَ المَدْفَنِ بِأكْمَلِه، وبَدا اللِّحاءُ المُتَبَقِّي مُقَشَّراً بِشَكْلٍ غَرِيب، مِثْلَ جِلْدِ الأُفْعوان.</p>
            <p>قَطَّبَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> جَبينَه. «وكَيْفَ لَنا أن نَتَحادَث، وهو سَجِينٌ هُناكَ وأنا هُنا في الأعلى؟»</p>
            <p>«إنَّهُ مُحاصَر. يَقولُ إنَّ عَلَيْكَ إغماضَ عَيْنَيْكَ وألَّا تُفَكِّرَ في شَيء. مِثْلَما تَفْعَلُ عِندَما تُقاتِل، كَما يَقول.»</p>
            <p>دُهِشَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>. «هل يَتَحَدَّثُ إلَيْكِ الآن؟»</p>
            <p>«نَعَم، ولَكِنَّهُ يَقولُ إنَّ هذا لَيْسَ كافِياً، لأنَّني لا أعْرِفُ ما يَكفي مِن... الكَلِمات. الكَلِماتِ والأشياء. يَجِبُ أن يُرِيَك. يَقولُ إنَّكَ فَعَلْتَ هذا مِن قَبْل.»</p>
            <p>قالَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>: «يَبدو أنَّني لَن أمْلِكَ أيَّ أسرار.»</p>
            <p>«لَيْسَ الكَثير، لا، هَذا ما يَقولُه، لِذا يَقولُ إنَّهُ سَيَفْعَلُ الشَّيءَ نَفْسَهُ في المُقابِل. حَتَّى تَتَمَكَّنا مِنَ الثِّقَةِ بَبَعضِكُما البَعْض. نَوْعاً ما.»</p>
            <p>«نَوْعاً ما. هل هَذِهِ كَلِمَتُه؟»</p>
            <p>أومَأَت بِرَأسِها.</p>
            <p>ابتَسَمَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>. «حَسَناً، أنا أُقَدِّرُ صِدْقَه. طَيِّب، سأُجَرِّبُ هَذا.» أغْلَقَ عَيْنَيْه. ظَلَّت يَدُ <span class="tt tt-name" data-tt="Kettle">كيتل</span> البارِدَةُ في يَدِه، صَغِيرَة، ولَحْمُها مُرْتَخٍ بِشَكْلٍ غَرِيبٍ على العِظام. سَحَبَ أفكارَهُ بَعِيداً عَن ذلِكَ التَّفْصِيل. <span class="tt tt-phil" data-tt="يستكشف الكاتب هنا سيكولوجية المحارب في مالازان. الانفصال العاطفي ليس غياباً للمشاعر أو العقل، بل حالة من التركيز المطلق والبقاء في الحاضر ببرود، وهو ما يبرز الانضباط القاسي.">لَم يَكُن عَقلُ المُقاتِلِ في الحَقِيقَةِ فارِغاً أثناءَ القِتال؛ بَل كانَ، بَدَلاً مِن ذلِكَ، مُنْفَصِلاً بِبُرودٍ ومُنْتَبِهاً في آنٍ واحِد. تَرْكِيزٌ يُعَرِّفُهُ بِنَاءٌ يَجري تَرْكِيبُهُ بدَوْرِهِ بِمُوجِبِ قَوانِينَ صارِمَةٍ مِنَ الضَّرورَةِ العَمَلِيَّة. وهكذا، كانَ تَرْكِيزاً قائِماً على المُلاحَظَة، والحِساب، وخالِياً تَماماً مِنَ العاطِفَة، حتَّى مَع استِيقاظِ كُلِّ حاسَّة.</span></p>
            <p>شَعَرَ بِنَفْسِهِ يَنْغَلِقُ داخِلَ ذلِكَ البِنَاءِ المَألوفِ والمُطَمْئِن.</p>
            <p>وصُدِمَ بِقُوَّةِ الإرادَةِ الَّتي جَذَبَتْهُ بَعِيداً. صَارَعَ ضِدَّ ذُعْرٍ مُتَصاعِد، عالِماً أنَّهُ عاجِزٌ أمامَ مِثْلِ هَذِهِ القُوَّة. ثُمَّ استَسْلَم.</p>
            <p>فَوْقَهُ، تَحَوَّلَتِ السَّماء. ضَوْءٌ أخضَرُ مُضْطَرِبٌ سَقِيمٌ يُحِيطُ بِجُرْحٍ أسوَدَ مُمَزَّقٍ كَبِيرٍ بِما يَكفي لِابْتِلاعِ قَمَر. تَلَوَّتِ الغُيوم، مُعَذَّبَةً ومَمْزوقَةً بِسَبَبِ هُبوطِ أشياءَ لا حَصْرَ لَها، وبَدا كُلُّ شَيءٍ وكأنَّهُ يُصارِعُ الهَواءَ وهو يَسقُط، وكأنَّ هذا العالَمَ كانَ يُقاوِمُ هذا التَّدَخُّلَ بِنَشاط. أشياءُ تَنْصَبُّ مِن ذلِكَ الجُرْح، تَحفُرُ طَرِيقَها عَبْرَ طَبَقاتِ السَّماء.</p>
            <p>على المَشْهَدِ الطبيعيِّ أمامَهُ، كانت هُناكَ مَدِينَةٌ شاسِعَة، تَرْتَفِعُ مِن سَهْلٍ مُسْتَوٍ بِحَدائِقَ مُدَرَّجَةٍ ومَمَرَّاتٍ مُرْتَفِعَة. ارتَفَعَت مَجْموعَةٌ مِنَ الأبراجِ مِنَ الجانِبِ البَعِيد، واصِلَةً إلى ارتِفاعاتٍ غَيرِ عادِيَّة. امْتَدَّتِ الأراضي الزِّراعِيَّةُ مِن ضَواحِي المَدِينَةِ في كُلِّ اتِّجاهٍ بِقَدْرِ ما يَستَطِيعُ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> رؤيَتَه، وظِلالٌ غَرِيبَةٌ تَتَدَفَّقُ فَوْقَها بَيْنما يُراقِب.</p>
            <p>سَحَبَ نَظَرَهُ عَنِ المَشْهَدِ ونَظَرَ إلى أسفَل، لِيَجِدَ أنَّهُ يَقِفُ على مَنَصَّةٍ مِنَ الحَجَرِ الجِيرِيِّ المُخَضَّبِ بِاللَّوْنِ الأحْمَر. أمامَهُ، جَرَت دَرَجاتٌ شَدِيدَةُ الانْحِدارِ نَحوَ الأسفَل، صَفَّاً تِلْوَ صَفّ، المِئاتُ مِنها، نَحوَ مِساحَةٍ مَرْصوفَةٍ تُحِيطُ بِها أعْمِدَةٌ مَطْلِيَّةٌ بِاللَّوْنِ الأزْرَق. كَشَفَت نَظرَةٌ إلى يَمِينِهِ عَن هُبوطٍ بِزاوِيَةٍ حادَّة. لَقَد كانَ على هَيْكَلٍ هَرَمِيِّ الشَّكْلِ ذي قِمَّةٍ مُسَطَّحَة، وأدْرَكَ بِذُعْرٍ أنَّ شَخْصاً ما يَقِفُ بِجانِبِه، عَن يَسارِه. شَكْلٌ بالكادِ مَرئِيّ، شَبَحِيّ، يَتَحَدَّى التَّفاصِيل. كانَ طَويلاً، وبَدا وكأنَّهُ يُحَدِّقُ في السَّماء، مُرَكِّزاً على ذلِكَ الجُرْحِ المُظلِمِ الرَّهِيب.</p>
            <p>كانتِ الأشياءُ تَرتَطِمُ بِالأرضِ الآن، تَهْبِطُ بِقُوَّةٍ ولَكِن لَيْسَ بِالسُّرعَةِ الَّتي يَنْبَغي أن تَمْلِكَها. دَوى صَوتُ صَدْعٍ عالٍ مِنَ السَّاحَةِ بَينَ الأعْمِدَةِ في الأسفَل، ورأى <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> أنَّ مَنْحوتَةً حَجَرِيَّةً ضَخْمَةً قَدِ استَقَرَّت هُناك. بَدا بَشَرِيَّاً غَرِيباً يُشْبِهُ الوَحْش، جَاثِماً بِأذْرُعٍ ذاتِ عَضَلاتٍ كَثِيفَةٍ تَصِلُ إلى الأمام، وتَلْتَقِي بِقَبْضَةٍ تَسْتَخْدِمُ كِلْتا اليَدَيْنِ على العُضْوِ الذَّكَرِيّ. صُنِعَتِ الأكتافُ والرَّأسُ على شَكْلِ ثَوْر. وهُناكَ مَجْموعَةٌ ثانِيَةٌ مِنَ الأرْجُل، أُنثَوِيَّة، تَلُفُّ خَصْرَ الرَّجُلِ الوَحْش، والمَنَصَّةُ الَّتي يَجْثو فَوْقَها مَنْحوتَةٌ — كَما يَرى <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> الآن — على شَكْلِ امْرأة، مُسْتَلْقِيَةٍ على ظَهْرِها تَحْتَه. ومِن مَكانٍ قَرِيب، ارتَفَعَ صَوتُ قَعْقَعَةِ العَشَراتِ مِنَ الألواحِ الطِّينِيَّة — كانَت بَعِيدَةً جِدَّاً بِحَيْثُ لا يُمكِنُ لِـ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> رؤيَةُ ما إذا كانت هُناكَ كِتابَةٌ عَلَيْها، رَغْمَ أنَّهُ شَكَّ في ذلِكَ — وهي تَنْزَلِقُ وكأنَّها على وَسائِدَ مِنَ الهَواءِ قَبْلَ أن تَسْتَقِرَّ في مَساحَةٍ مُشَتَّتَة.</p>
            <p>شَظايا مَبَانٍ — كُتَلٌ مِنَ الحَجَرِ الجِيرِيِّ المَنْحوت، أحجارُ زاوِيَة، جُدرانٌ مِنَ اللَّبِن، وأغصانٌ مَطْلِيَّةٌ بِالطِّين. ثُمَّ أطرافٌ مَقْطوعَة، وأجزاءٌ مِن مَاشِيَةٍ وخُيولٍ مُسْتَنْزَفَةِ الدِّماء، وقَطِيعٌ مِن شَيءٍ رُبَّما كانَ مَاعِزاً، لَقَد قُلِبَ كُلُّ واحِدٍ مِنها مِنَ الداخِلِ إلى الخارِج، وأمعاؤُهُ تَتَدَلَّى. بَشَرٌ ذوو بَشَرَةٍ داكِنَة — أو على الأقَلِّ أذْرُعُهُم وأرجُلُهُم وجُذوعُهُم.</p>
            <p>في الأعلى، كانتِ السَّماءُ تَمْتَلِئُ بِشَظايا ضَخْمَةٍ شاحِبَة، تَهْبِطُ مِثْلَ الثَّلْج.</p>
            <p>وشَيءٌ ضَخْمٌ كانَ يَمُرُّ عَبْرَ الجُرْح. مُحاطاً بِبَرْقٍ بَدا وكأنَّهُ يَصْرُخُ مِنَ الألم، صَرخاتٌ لا تَنْتَهِي، تُصِمُّ الآذان.</p>
            <p>تَحَدَّثَت كَلِماتٌ ناعِمَةٌ في عَقلِ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>. «شَبَحِي، أُطْلِقَ لِيَهيمَ، رُبَّما، لِيَشْهَد. لَقَد حارَبوا ضِدَّ <span class="tt tt-lore" data-tt="الملك الأعلى الأسطوري. طاغية خالد دمر إمبراطوريته العظيمة وقتل الملايين من شعبه بدلاً من الاستسلام للآلهة القديمة. (Kallor)">كالور</span>؛ لَقَد كانت قَضِيَّةً جَدِيرَة. ولَكِن... ما فَعَلوهُ هُنا...»</p>
            <p>لَم يَسْتَطِع <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> سَحْبَ عَيْنَيْهِ عَن تِلكَ الكُرَةِ الصارِخَةِ مِنَ البَرْق. كانَ يُمكِنُهُ رؤيَةُ أطرافٍ داخِلَها، والأقواسُ المُتَوَهِّجَةُ مُلْتَفَّةٌ حَوْلَها مِثْلَ السَّلاسِل. «ما— ما هَذا؟»</p>
            <p>«إلَهٌ يا <span class="tt tt-name" data-tt="Brys Beddict">بريس بيديكت</span>. في عالَمِهِ الخاصّ، كانَ مَحْبوساً في حَرْب. فَقَد كانت هُناكَ آلِهَةٌ مُنافِسَة. إغراءاتٌ...»</p>
            <p>سألَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>: «هل هَذِهِ رُؤيا مِنَ الماضي؟»</p>
            <p>أجابَ الشَّخْص: «<span class="tt tt-phil" data-tt="فلسفة حول الزمن وتكرار أخطاء التاريخ في عالم مالازان. البشر يفضلون الجهل الطوعي ونسيان دورات العنف السابقة، لأن إدراكها الكامل سيؤدي إلى فقدان الأمل التام والجنون.">الماضي لا يَزالُ حَيَّاً. لا توجَدُ طَرِيقَةٌ لِلْمَعْرِفَة... ونَحنُ نَقِفُ هُنا. كَيْفَ نَقِيسُ البِدايَة، والنِّهايَة — بالنسبةِ لَنا جَمِيعاً، كانَ الأَمْسُ كاليَوْم، وكَما سَيَكونُ غَداً. نَحنُ لَسْنا مُدْرِكِين. أو رُبَّما نَحنُ كَذلِك، ومَع ذلِكَ نَخْتار — مِن أجلِ الرَّاحَة، ومِن أجلِ سَلامَةِ العَقْل — ألَّا نَرى. ألَّا نُفَكِّر.</span>» قَامَ بِإِيماءَةٍ غامِضَةٍ بِيَدٍ واحِدَة. «البَعْضُ يَقولونَ اثنا عَشَرَ ساحِراً، والبَعْضُ يَقولونَ سَبْعَة. لا يَهُم، فَهُم على وَشْكِ أن يُصْبِحوا هَباءً.»</p>
            <p>كانتِ الكُرَةُ الضَّخْمَةُ تَزْأَرُ الآن، وتَنْمُو بِسُرعَةٍ مُخِيفَةٍ وهي تَهْوي نَحوَ الأرض. وأدْرَكَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span> أنَّها سَتَضْرِبُ المَدِينَة.</p>
            <p>«<span class="tt tt-phil" data-tt="تحذير فلسفي من أن السعي المتعجرف للتحكم المطلق في المصير وتغيير النظام الطبيعي (عبر استدعاء إله غريب) يؤدي حتماً إلى تدمير الذات وانهيار الحضارات بأكملها.">وهَكذا، في جُهْدِهِم لِفَرْضِ تَغْيِيرٍ على المُخَطَّط، فإنَّهُم يُبِيدونَ أنفُسَهُم، وحَضارَتَهُم الخاصَّة.</span>»</p>
            <p>«إذاً لَقَد فَشِلوا.»</p>
            <p>لَم يَقُلِ الشَّخْصُ شَيئاً لِفَترَة.</p>
            <p>واصطَدَمَ الإلَهُ الهابِط؛ وَمِيضٌ يُعْمِي الأبصار، انْفِجارٌ زَلْزَلَ الهَرَمَ تَحتَهُما وأرسَلَ شُقوقاً عَبْرَ السَّاحَةِ في الأسفَل. دُخانٌ، يَرْتَفِعُ في عَمودٍ ثُمَّ يَنْدَفِعُ نَحوَ الخارِج، مُبْتَلِعاً العالَمَ في الظِّلّ. انْدَفَعَتِ الرِّياحُ نَحوَ الخارِج في صَدْمَة، مُحَطِّمَةً الأشجارَ في الأراضي الزِّراعِيَّة، ومُسْقِطَةً الأعْمِدَةَ التي تُصَفُّ السَّاحَة. ثُمَّ انْدَلَعَتِ النِّيرانُ في الأشجار.</p>
            <p>«استِجابَةً لِيَأْسٍ مَحْسوس، يُغَذِّيهِ غَضَبٌ مُتَأجِّج، استَدْعَوْا إلهاً. ومَاتوا مَع هذا الجُهْد. هل يَعنِي ذلِكَ أنَّهُم فَشِلوا في مُقامَرَتِهِم؟ لا، أنا لا أتَحَدَّثُ عَن <span class="tt tt-lore" data-tt="الطاغية الخالد. (Kallor)">كالور</span>. أنا أتَحَدَّثُ عَن عَجْزِهِم الَّذي أدى إلى نُشوءِ رَغْبَتِهِم في التَّغْيِير. <span class="tt tt-name" data-tt="Brys Beddict">بريس بيديكت</span>، لَوْ كانَت أشْباحُهُم تَقِفُ مَعَنا الآن، هُنا في عالَمِ المُستَقْبَلِ حَيْثُ تَقْبَعُ أجسادُنا، وبِالتَّالي قادِرَةً على رؤيَةِ ما صَنَعَهُ فِعْلُهُم، لَأَدْركوا أنَّ كُلَّ ما سَعَوْا إلَيْهِ قَد تَحَقَّق.</p>
            <p>«إنَّ ذلِكَ الَّذي كانَ مُقَيَّداً في الأرضِ قَد حَرَّفَ جُدْرانَ سِجْنِه. بِيَدٍ لا يُمكِنُ التَّعَرُّفُ عَلَيْها. لَقَدِ انْتَشَرَ سُمُّهُ وأصابَ العالَمَ وكُلَّ مَن يَعِيشُ فَوْقَه.»</p>
            <p>قالَ <span class="tt tt-name" data-tt="Brys Beddict">بريس</span>: «أنتَ تَتْرُكُني بِلا أمَل.»</p>
            <p>«أنا آسِفٌ لِذلِك. <span class="tt tt-phil" data-tt="نقد لاذع لطبيعة السلطة والقيادة. القادة يستخدمون مفاهيم مثل 'الواجب' و'الطاعة' كأدوات للسيطرة، ويعتبرون التفكير النقدي أو التساؤل تهديداً مباشراً لنفوذهم.">لا تَبْحَثْ عَنِ الأمَلِ بَينَ قادَتِك. فَهُم مُسْتَوْدَعاتُ السُّمّ. اهتِمامُهُم بِكَ يَمْتَدُّ فَقَط بِقَدْرِ قُدرَتِهِم على التَّحَكُّمِ فِيك. ومِنْك، يَسْعَوْنَ لِلواجِبِ والطَّاعَة، وسَيُزَوِّدونَكَ بِلُغَةِ الإيمانِ المُؤَثِّرَة. إنَّهُم يَبْحَثونَ عَنِ الأتباع، والوَيْلُ لِمَن يَتَساءَل، أو يَرْفَعُ صَوتَ التَّحَدُِّي.</span></p>

    <script>
        // State
        const state = {
            font: 'Amiri',
            fontSize: 20,
            lineHeight: 2.0,

            toggles: { name: true, lore: true, phil: true }

        // DOM Elements
        const docEl = document.documentElement;
        const body = document.body;
        const btnSettings = document.getElementById('btn-settings');
        const overlay = document.getElementById('settings-overlay');
        const panel = document.getElementById('settings-panel');
        const progressBar = document.getElementById('progress-bar');
        const btnScrollTop = document.getElementById('scroll-top');
        const tooltip = document.getElementById('global-tooltip');
        const tooltipContent = document.getElementById('global-tooltip-content');
        const toastEl = document.getElementById('toast');

        // Number conversion
        const toArabicNumerals = (str) => {
            return str.toString().replace(/[0-9]/g, c => String.fromCharCode(c.charCodeAt(0) + 1584));
        };

        // --- Settings Logic ---
        
        // Font
        document.querySelectorAll('.font-btn').forEach(btn => {
            btn.addEventListener('click', (e) => {
                document.querySelectorAll('.font-btn').forEach(b => b.classList.remove('active'));
                btn.classList.add('active');
                state.font = btn.getAttribute('data-font');
                docEl.style.setProperty('--font-family', `'${state.font}', ${state.font === 'Amiri' || state.font === 'Noto Naskh Arabic' ? 'serif' : 'sans-serif'}`);
                showToast(`الخط: ${btn.textContent}`);
            });
        });

        // Font Size
        const sliderFs = document.getElementById('slider-fs');
        const valFs = document.getElementById('val-fs');
        sliderFs.addEventListener('input', (e) => {
            state.fontSize = e.target.value;
            valFs.textContent = toArabicNumerals(state.fontSize);
            docEl.style.setProperty('--font-size', `${state.fontSize}px`);
        });

        // Line Height
        const sliderLh = document.getElementById('slider-lh');
        const valLh = document.getElementById('val-lh');
        sliderLh.addEventListener('input', (e) => {
            state.lineHeight = parseFloat(e.target.value).toFixed(1);
            valLh.textContent = toArabicNumerals(state.lineHeight);
            docEl.style.setProperty('--line-height', state.lineHeight);
        });

        // Themes
        const swatches = document.querySelectorAll('.swatch');
        swatches.forEach(swatch => {
            swatch.addEventListener('click', () => {
                swatches.forEach(s => s.classList.remove('active'));
                swatch.classList.add('active');
                state.theme = swatch.getAttribute('data-theme');
                body.setAttribute('data-theme', state.theme);
                showToast(`المظهر: ${state.theme}`);
            });
        });

        // Toggles
        document.querySelectorAll('.toggle-switch').forEach(toggle => {
            toggle.addEventListener('click', () => {
                const type = toggle.getAttribute('data-toggle');
                toggle.classList.toggle('off');
                state.toggles[type] = !toggle.classList.contains('off');
                if (state.toggles[type]) {
                    body.classList.remove(`hide-${type}`);
                } else {
                    body.classList.add(`hide-${type}`);
                }
            });
        });

        // Panel open/close
        const togglePanel = () => {
            const isShowing = panel.classList.contains('show');
            if (isShowing) {
                panel.classList.remove('show');
                overlay.classList.remove('show');
            } else {
                panel.classList.add('show');
                overlay.classList.add('show');
            }
        };
        btnSettings.addEventListener('click', togglePanel);
        overlay.addEventListener('click', togglePanel);

        // --- Scroll Logic ---
        let isScrolling = false;
        window.addEventListener('scroll', () => {
            if (!isScrolling) {
                window.requestAnimationFrame(() => {
                    // Progress bar
                    const scrollTop = window.scrollY || document.documentElement.scrollTop;
                    const scrollHeight = document.documentElement.scrollHeight - document.documentElement.clientHeight;
                    const scrolled = (scrollTop / scrollHeight) * 100;
                    progressBar.style.width = scrolled + '%';

                    // Scroll to top button
                    if (scrollTop > 400) {
                        btnScrollTop.classList.add('visible');
                    } else {
                        btnScrollTop.classList.remove('visible');
                    }
                    
                    isScrolling = false;
                });
                isScrolling = true;

        btnScrollTop.addEventListener('click', () => {
            window.scrollTo({ top: 0, behavior: 'smooth' });

        // --- Tooltips Logic ---
        let tooltipTimeout;
        let activeEl = null;

        const showTT = (target) => {
            if(activeEl === target) return;
            activeEl = target;
            
            const text = target.getAttribute('data-tt');
            tooltipContent.textContent = text;
            
            tooltip.className = ''; // reset classes
            if (target.classList.contains('tt-name')) tooltip.classList.add('type-name');
            if (target.classList.contains('tt-lore')) tooltip.classList.add('type-lore');
            if (target.classList.contains('tt-phil')) tooltip.classList.add('type-phil');

            const rect = target.getBoundingClientRect();
            
            // Temporary show to get dimensions
            tooltip.style.display = 'block';
            tooltip.classList.add('show');
            const ttRect = tooltip.getBoundingClientRect();
            
            let topPos = rect.top + window.scrollY - ttRect.height - 10;
            let leftPos = rect.left + window.scrollX + (rect.width / 2) - (ttRect.width / 2);
            
            tooltip.classList.add('pos-top');
            
            // Flip to bottom if not enough space
            if (rect.top - ttRect.height - 10 < 0) {
                topPos = rect.bottom + window.scrollY + 10;
                tooltip.classList.remove('pos-top');
                tooltip.classList.add('pos-bottom');
            }

            // Screen edge collision
            if (leftPos < 10) leftPos = 10;
            if (leftPos + ttRect.width > window.innerWidth - 10) {
                leftPos = window.innerWidth - ttRect.width - 10;
            }

            tooltip.style.top = `${topPos}px`;
            tooltip.style.left = `${leftPos}px`;
        };

        const hideTT = () => {
            tooltip.classList.remove('show');
            activeEl = null;
        };

        document.addEventListener('mouseover', (e) => {
            const target = e.target.closest('.tt');
            if (!target) return;
            if (window.innerWidth < 768) return; // handled by click on mobile

            showTT(target);

        document.addEventListener('mouseout', (e) => {

            if (!target) return;
            if (window.innerWidth < 768) return;
            tooltipTimeout = setTimeout(hideTT, 150);
        });

        // Mobile tap & close button logic
        document.addEventListener('click', (e) => {
            const target = e.target.closest('.tt');
            const closeBtn = e.target.closest('.tt-close-btn');
            
            if (closeBtn) {
                hideTT();
                return;
            }
            
            if (target && window.innerWidth < 768) {
                e.preventDefault();
                showTT(target);
                return;
            }
            
            // Click outside dismiss
            if (window.innerWidth < 768 && !e.target.closest('#global-tooltip') && !target) {
                hideTT();
            }
        });
        
        // Prevent tooltip from disappearing when hovering over it
        tooltip.addEventListener('mouseenter', () => clearTimeout(tooltipTimeout));
        tooltip.addEventListener('mouseleave', () => {
            if (window.innerWidth >= 768) tooltipTimeout = setTimeout(hideTT, 150);
        });

        // --- Keyboard Shortcuts ---
        let toastTimeout;
        const showToast = (msg) => {
            toastEl.textContent = msg;
            toastEl.classList.add('show');
            clearTimeout(toastTimeout);
            toastTimeout = setTimeout(() => toastEl.classList.remove('show'), 1500);
        };

        window.addEventListener('keydown', (e) => {
            // Ignore if in inputs (none here, but good practice)
            if (e.target.tagName === 'INPUT' || e.target.tagName === 'TEXTAREA') return;

            if (e.key === '+' || e.key === '=') {
                if (state.fontSize < 28) {
                    sliderFs.value = ++state.fontSize;
                    sliderFs.dispatchEvent(new Event('input'));
                    showToast(`حجم الخط: ${toArabicNumerals(state.fontSize)}`);
                }
            } else if (e.key === '-') {
                if (state.fontSize > 14) {
                    sliderFs.value = --state.fontSize;
                    sliderFs.dispatchEvent(new Event('input'));
                    showToast(`حجم الخط: ${toArabicNumerals(state.fontSize)}`);
                }
            } else if (e.key.toLowerCase() === 't') {
                const themes = ['cream', 'white', 'dark', 'amoled'];
                let idx = themes.indexOf(state.theme);
                idx = (idx + 1) % themes.length;
                swatches[idx].click();
            } else if (e.key.toLowerCase() === 's') {
                togglePanel();
            } else if (e.key === 'Escape') {
                if (panel.classList.contains('show')) togglePanel();
                hideTT();
            } else if (e.key === 'Home') {
                window.scrollTo({ top: 0, behavior: 'smooth' });
            }
        });

    </script>
</body>
